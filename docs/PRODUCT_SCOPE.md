# MVP Scope

The first supported question is: **Should this client buy this U.S.-listed stock?**

Inputs:
- ticker
- proposed amount
- portfolio value
- current sector exposure
- risk tolerance
- investment horizon

Outputs:
- buy / buy partially / hold
- confidence
- proposed amount and allocation
- committee member opinions
- reasons, risks and review triggers

Out of scope for MVP 0.1:
- order execution
- options, crypto and derivatives
- tax advice
- autonomous portfolio management
- return guarantees
